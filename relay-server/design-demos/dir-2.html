claude-codex-wechat 接入指南

指南

在本机跑一个桥接程序，就能用微信直接驱动你电脑上的 Claude Code / Codex 会话。装好、启动、扫码，即可使用，全程无需改配置。

0准备

  • 本机已安装 Node.js ≥ 20。
  • 已安装并登录好要用的 claude 或 codex 命令行。

1安装

终端
npm install -g claude-codex-wechat --registry=https://registry.npmmirror.com/

2启动

后台启动即可（首次启动会自动生成接入凭据、自动连接中转，无需任何配置）：

终端
claude-codex-wechat start

用 claude-codex-wechat status 可随时查看运行状态。

3扫码绑定微信

启动后，在本机浏览器打开管理页，用微信扫码登录即可完成绑定：

浏览器
http://127.0.0.1:8787

4开始使用

  • 直接在微信里给机器人发消息，像聊天一样让它在你电脑上干活——读写代码、执行命令、改文件。
  • 它跑在你自己的电脑上，用的就是你本机的 Claude / Codex 和项目文件。
  • 随时离开、稍后再发消息，都能接着上次的会话继续，不用重新开始。

↑更新

已经装过了、想升级到最新版，运行这一条即可（自动拉取新版并重启服务）：

终端
claude-codex-wechat upgrade

若提示「未知命令」，说明当前装的还是没有该命令的旧版本，改用下面两条：

终端
npm install -g claude-codex-wechat@latest --registry=https://registry.npmmirror.com/
claude-codex-wechat restart

×卸载

不想用了，先停止并移除后台服务，再删除全局安装的程序：

终端
claude-codex-wechat uninstall
npm uninstall -g claude-codex-wechat

以上两条在 macOS / Linux / Windows 上通用。如需同时清除本地配置、微信登录状态和日志，再删除数据目录：

macOS / Linux：

终端
rm -rf ~/.claude-codex-wechat

Windows（PowerShell）：

PowerShell
Remove-Item -Recurse -Force "$env:USERPROFILE\.claude-codex-wechat"
