# 方向卡（六个候选 → 选三张做完整版）

轮盘：date +%S = 48 → 网页库 48%20+1 = 9 号「像素游戏横版叙事」；东亚库 48%12+1 = 1 号「吕敬人书籍设计」。

## ✅ 方向 1 · 协作画布（现实参照：Figma 多人画布 / Joel Califa 的 Swarm 概念）
- 借的是什么：浅灰点阵画布 + 一张白色 artboard；左上「Frame」标签；顶部和左侧细标尺；选中框蓝色 1px + 四角小方块手柄；尺寸徽标 `W × H` 蓝底白字；红色参考线（#F24822）吸附。多人光标：彩色箭头 + 名字胶囊（Claude 橙、Codex 绿、微信 绿/蓝区分开），每人负责不同区块。
- 主角素材：光标本身和它们的「施工痕迹」（选框、尺寸徽标、参考线），程序化，零图片。
- 骨架：单列 artboard 居中（max 820），步骤是一个个 frame；标尺固定在视口边缘。
- 胆量花在哪：搭完后不全部清理——每个 frame 左上保留极淡的 frame 名（如「Step / 安装」），像设计稿交付态；光标搭完后聚到右下角排队待命，悬停任意卡片时某个光标会过来「指」一下（轻量）。
- form 来自内容的哪里：产品就是「多个 agent 同时在你电脑上干活」，页面由多人光标协作搭出来。

## ✅ 方向 2 · 稿纸排字（秒数轮盘：吕敬人书籍设计 → 东亚）
- 借的是什么：吕敬人的书籍设计思维——网格即秩序、文字本身是图像、天头地脚留白、书口竖排小标题、朱红单点缀（印章红 #B8352B）与墨黑、米白纸（#F3EFE6 一类，非奶油橙）。中文为主角：标题用宋体/明体栈（"Songti SC", "STSong", "Noto Serif CJK SC", serif），正文黑体栈。
- 主角素材：方格稿纸网格（CSS background 画 20×20 字格），标题字逐格「排」进格子里；光标是一支朱红 I-beam 排字光标 + 两个小光标，像三位排字工。
- 骨架：左侧窄栏竖排步骤名（准备/安装/启动/扫码/使用/更新/卸载），右侧主栏内容；移动端竖排栏变横向页眉。命令块用墨黑底 + 米白字，像版心里的一块嵌板。
- 胆量花在哪：首屏标题在稿纸格里一字一格打出，每字落格时格线微亮；朱红印章式的「已复制」反馈。
- form 来自内容的哪里：这是一份「指南」——一本小册子，光标在排版它。

## ✅ 方向 3 · 大字报施工（现实参照：Bloomberg Businessweek 2010–14 / 网页库 1 号媒体级粗野主义）
- 借的是什么：纯白底 + 纯黑 + 超链接蓝 #0000EE 单点缀；巨号无衬线标题（clamp 到 120px+，紧字距）直接压住 15px 正文；1px 黑色规则线分栏；模块网格高密度。
- 主角素材：巨字本身——首屏「装好 启动 扫码」三个巨型动词由光标拖框后打出来；规则线由光标用「钢笔工具」拉出来。
- 骨架：桌面 12 栏网格：左 4 栏步骤号与动词巨字，右 8 栏命令与说明；每步之间一条通栏规则线。移动端单列。
- 胆量花在哪：首屏字号反差（巨字 vs 小正文），光标拖框时尺寸徽标用超链接蓝。
- form 来自内容的哪里：整个上手只有三个动作，就把三个动词做成海报。
